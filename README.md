# Brozen AI Telegram Bot

ربات فروش پلن تلگرام با پنل مدیریت، پرداخت کارت‌به‌کارت و تأیید دستی رسید.

## امکانات
- پیام خوش‌آمدگویی قابل تنظیم و استفاده از `{name}`
- افزودن/ویرایش/حذف/فعال‌سازی پلن‌ها از پنل ادمین
- قیمت به تومان، توضیحات و مدت/اعتبار هر پلن
- تنظیم شماره کارت، نام صاحب کارت، راهنمای پرداخت و پشتیبانی
- دریافت عکس یا فایل تصویری رسید و ارسال برای ادمین‌ها
- تأیید یا رد پرداخت توسط ادمین؛ ارسال نتیجه به کاربر
- تاریخچه سفارش، پروفایل، آمار و پیام همگانی
- SQLite برای ذخیره داده‌ها

## فایل‌ها
`bot.py`, `requirements.txt`, `Procfile`, `runtime.txt`, `.env.example`, `.gitignore`, `README.md`

## Railway
1. این پروژه را به یک مخزن GitHub خصوصی آپلود کن و در Railway از آن Deploy بگیر.
2. در Variables این موارد را تنظیم کن:
   - `BOT_TOKEN`: توکن BotFather؛ آن را عمومی نکن.
   - `ADMIN_IDS`: شناسه عددی تلگرام ادمین‌ها، با کاما جداشده؛ مثال `123456789,987654321`.
   - `CARD_NUMBER`, `CARD_NAME`: اختیاری؛ مقادیر اولیه که بعداً در پنل قابل تغییرند.
   - `SUPPORT_USERNAME`: اختیاری، پیش‌فرض `IBrOzen`.
   - `DB_PATH`: مسیر دیتابیس؛ برای Volume متصل به `/data` مقدار `/data/brozen_ai.db`.
3. فایل `Procfile` سرویس را به صورت worker اجرا می‌کند؛ برای polling نیازی به web server نیست.
4. بعد از Deploy به ربات `/start` بده و با اکانت ادمین `/admin` را اجرا کن.

## دیتابیس پایدار
برای جلوگیری از حذف اطلاعات در تعویض کانتینر، یک Railway Volume در مسیر `/data` وصل کن و `DB_PATH=/data/brozen_ai.db` بگذار. بدون Volume ممکن است دیتابیس محلی در redeploy از دست برود.

## پرداخت و فعال‌سازی
این نسخه درگاه بانکی آنلاین ندارد؛ پرداخت کارت‌به‌کارت است و ادمین رسید را دستی بررسی می‌کند. پس از تأیید، ربات پیام تأیید می‌فرستد اما سرویس/پلن خارجی را خودکار فعال نمی‌کند.

## نکات
- فقط یک نمونه polling با یک توکن را هم‌زمان اجرا کن تا خطای conflict ایجاد نشود.
- ابتدا یک سفارش آزمایشی انجام بده.
- اگر توکن در جایی منتشر شد، از BotFather آن را revoke/regenerate کن.
